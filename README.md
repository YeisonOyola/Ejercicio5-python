# Ejercicio 5 Python

Programa desarrollado en Python para calcular las horas trabajadas por un equipo durante la semana.

## Funcionalidades
- Registro de horas trabajadas
- Cálculo total de horas semanales
- Clasificación de jornada:
  - Horario Estándar
  - Sobretiempo

## Tecnologías
